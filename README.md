# orb.

**orb.** is a decentralized, peer-to-peer electronic cash and long-term store of value system in active development.

It follows the original principles of Bitcoin — simplicity, resilience, and decentralization — but with a clean chain, fixed supply, and no premine or venture capital. orb. is for those who care about protocol minimalism, transparency, and self-sovereignty.

---

## Key Properties

- **Token name:** orb.
- **Symbol:** ORB
- **Maximum supply:** 10,000,000 ORB (fixed)
- **Initial block reward:** 50 ORB
- **Halving interval:** Every 210,000 blocks (~4 years)
- **Consensus algorithm:** Yescrypt Proof-of-Work (CPU-friendly)
- **Block time:** ~10 minutes
- **Decimals:** 6
- **Genesis reward:** 50 ORB
- **Launch status:** In early development
- **Monetary policy:** Transparent, predictable, no premine

---

## Philosophy

orb. is not built for hype. It’s built for long-term sustainability, inspired by the cypherpunk ideals of privacy, decentralization, and code-as-law.

- No ICO, no airdrop, no insider allocation  
- Fully open-source from day one  
- Minimalist codebase, clean fork of Bitcoin  
- Honest proof-of-work mining

## Development Status

The project is based on Bitcoin Core, stripped to its essentials. orb. is being built slowly and publicly.
